# Wave 2026-09-16 — Golden Frijoles gets a write surface

An agent-first product whose only write path is "log into the console" is not agent-first. Today the
connector is read-only and demo-scoped, and `medusa-bonsai` wrote a 200-line Flagsmith wrapper
because there was no vendor CLI. The `dobby-foundation` mandate that makes Golden Frijoles the
required flag provider for every sibling project **cannot ship without this**.

| Bet | Appetite | Displaced (the opportunity cost) |
|---|---|---|
| **#28 [Golden Frijoles CLI v1](../02-commercial/golden-frijoles-cli/README.md)** — auth, `init`, the full flag lifecycle, one-line installer, MCP parity | **L** (multi-wave epic, re-bet at each wave boundary) | The CMS-integration spike stays scaffolded-not-started for another wave. Analytics visualization and the Git & Releases discovery spike stay unfunded. Scenarios follow-ups wait |

The `dobby-foundation` half of this wave is recorded in
[`medusa-bonsai/Roadmap/bets/wave-2026-09-16.md`](../../../medusa-bonsai/Roadmap/bets/wave-2026-09-16.md).

**Decisions of record.**

- **Underwritten by the product owner's 2026-09-16 approval** of
  [`00-ideas/seeds/golden-frijoles-cli.md`](../00-ideas/seeds/golden-frijoles-cli.md).
- **Flags-first, deliberately.** Telemetry stays the SDK's path (AGENTS rule #1 — never a parallel
  pipeline). Experiments, journeys, north-star, scenarios, destinations and breakers are **out of
  v1**; naming them would triple the appetite. They get the same shared-command-core treatment in v2.
- **The command core is pure and shared.** One function per verb, zero I/O, called by both the CLI and
  any MCP write tool. **Parity is structural, not a review checklist.**
- **Audit before widening MCP.** Sprint 3 produces a written parity table and no code; only the gaps
  that table names get closed. AGENTS rule #2 (public paths serve the demo project only) and rule #3
  (the connector is enablement-gated) are **not relaxed** — their exclusions are marked deliberate.
- **The plan model is written down and not enforced.** Free = 50k evaluations/month, 1 project, 1
  seat, **unlimited flags · environments · segments** (Flagsmith's shape). Today every account is
  unlimited and every user is one of ours, so **the CLI builds no plan awareness, no quota display,
  no upgrade prompts and no limit errors in v1.** Metering and enforcement is a later epic.
- **The gating flag fails CLOSED**, inverting this product's normal fail-open rule. A flag-read
  failure that granted write access would be the worst possible bug in a flag product, and the
  epic's `D`-decisions name the inversion explicitly.
- **Auth is a console-minted PAT in Sprint 1**, not a device-code grant. Device code is a real OAuth
  primitive against a browser-SSR flow and is an appetite trap; it moves to Sprint 3 only if there is
  budget.
