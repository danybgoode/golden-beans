②Buttons — the push actually pays off now

③Honesty badges & tool calls — icons instead of emoji

Same meaning, consistent rendering

Emoji render differently per OS/browser and break the kraft-stamp/brass restraint the rest of the system holds to. These are concept icons (simple stroke shapes) — swap for the real iconoir-react set or a small vendored SVG file at build time; the mapping is what matters here.
